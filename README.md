# 🏋️ CrossFit Union Square — Gym Website

CrossFit Union Square is a **responsive gym website** designed to present information about a fitness center and provide users with an engaging way to explore its training programs, classes, memberships, events, and contact information.

This project demonstrates my **practical frontend development skills**, with a focus on writing a well-structured webpage using **semantic HTML5 elements**, responsive layouts, reusable Bootstrap components, organized CSS, and a clean website structure.

---

## ✨ Features

* 🏋️ Gym-focused landing page
* 🎯 Hero section with Join Now and Drop In options
* 📚 Training and CrossFit information
* 🏃 Classes section
* 💬 Customer testimonials
* 🖼️ Responsive image gallery
* 📱 Responsive navigation for mobile devices
* 📋 Bootstrap offcanvas navigation menu
* 📍 Google Maps location integration
* 📞 Contact information
* 📱 Responsive design for different screen sizes
* 🔗 Social media and contact links
* 🦾 Modern fitness-focused visual design

---

## 🧱 HTML & Semantic Elements

A major focus of this project was practicing **proper HTML5 structure and semantic elements**.

The website is organized using SEO Tags.

Semantic elements help create a meaningful document structure and improve:

* Code readability
* Accessibility
* Maintainability
* SEO structure
* Overall HTML organization

The webpage follows a clear hierarchy where the header contains the primary navigation and hero area, the main element contains the primary website sections, and the footer contains contact, training, company, social, and location information.

---

## 📱 Responsive Design

The website is built to work across multiple screen sizes:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

Bootstrap 5's responsive grid system and utility classes are used to create flexible layouts.
